ChatGPT Windows Loading Fix

Microsoft Store의 일반 ChatGPT Windows 앱이 중앙의 GPT 로고 화면에서 더 이상 진행되지 않을 때 사용하는 비공식 PowerShell 실행기입니다.

GitHub 저장소 열기 스크립트 다운로드

지원 환경

  • Windows 10 또는 Windows 11
  • Microsoft Store에서 설치한 일반 ChatGPT 앱 (OpenAI.Codex)
  • Windows PowerShell 5.1

해결하는 증상

ChatGPT 앱을 실행한 뒤 GPT 로고만 표시되고 홈 화면이 로드되지 않는 특정 라우팅 문제를 우회합니다. 설치된 Store 패키지를 찾아 공식 앱을 다시 활성화하고, 유효한 초기 화면 경로를 준비합니다.

사용 방법과 소스 코드

전체 설치 방법, 보안 참고 사항, 문제 해결 절차와 공개된 PowerShell 소스 코드는 GitHub 저장소에서 확인할 수 있습니다.

이 프로젝트는 OpenAI의 공식 도구가 아니며 OpenAI와 제휴하거나 보증받지 않았습니다. 특정 Windows 앱 로딩 오류를 위한 임시 우회책입니다.
